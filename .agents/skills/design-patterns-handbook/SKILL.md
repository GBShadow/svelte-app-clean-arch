# 🏛️ Design Patterns Handbook

## 🎯 Objetivo
Aplicar padrões de projeto consolidados para resolver problemas recorrentes de design de software com elegância.

---

## 🛠️ Padrões Mais Frequentes
1. **Strategy**: Substituir blocos `switch/case` extensos por objetos de estratégia intercambiáveis.
2. **Adapter**: Converter interfaces incompatíveis entre bibliotecas externas e contratos de domínio da aplicação.
3. **Decorator**: Adicionar responsabilidades a objetos dinamicamente (ex: logging, caching, autorização) sem alterar a classe original.
