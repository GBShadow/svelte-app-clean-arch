# 🔴🟢🔵 TDD Workflow Enforcer

## 🎯 Objetivo
Garantir cobertura e design limpo através da criação do teste de falha antes de qualquer linha de código de produção.

---

## 🔄 Ciclo TDD
1. **Red**: Escrever o teste unitário que define a especificação do comportamento desejado e confirmar sua falha.
2. **Green**: Escrever o código mínimo necessário para fazer o teste passar (sem antecipar otimizações).
3. **Refactor**: Limpar duplicações, melhorar nomes e arquitetura mantendo a suíte de testes verde.
