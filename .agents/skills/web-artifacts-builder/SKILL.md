# Web Artifacts Builder & Pipeline Skill

## Purpose & Scope
Orchestrates the build, bundling, and integrity verification of interactive web applications, components, and single-file artifacts. Ensures that code generated by AI models is syntactically valid, has all required dependencies resolved, and compiles without warnings or errors.

## Standard Build Protocol
1. **Dependency Resolution**:
   - Verify that all imported packages exist in `package.json`.
   - Ensure peer dependencies (e.g. Radix UI primitives, Lucide icons, clsx, tailwind-merge) are present.
2. **Type Checking & Linting**:
   - Run `tsc --noEmit` or `vue-tsc --noEmit` to verify type soundess across all components.
   - Run linter/formatter checks (`biome check` or `eslint`).
3. **Bundling & Production Artifact Verification**:
   - Execute production build (`vite build` / `next build`).
   - Validate asset generation, code splitting chunks, and absence of broken relative asset paths.
4. **Self-Contained Artifacts**:
   - When generating standalone HTML artifacts (single-file distribution), ensure CSS is properly inlined, scripts are compiled into bundle format, and external fonts/assets have valid fallback strategies.
